```bash
# Basic conversion
mdtopdf convert document.md

# With dark theme
mdtopdf convert document.md -t github-dark

# Batch processing
mdtopdf convert *.md -o pdfs/

# List all templates
mdtopdf templates list

# Show configuration
mdtopdf config show
```
